# Flet-AGENTS.md
I've created a comprehensive AGENTS.md file for the flet-dev project! This guide is designed to help AI assistants  work effectively with Flet framework projects.
The file covers:

Framework overview - What Flet is and its key characteristics
Programming paradigms - Both imperative and declarative styles with examples
Best practices - Version awareness, code generation guidelines, common controls
Project structure - Single-file and multi-module patterns
Deployment patterns - Web (WASM/server-side), desktop, and mobile
Common patterns - Routing, responsive design, services usage
Styling and theming - How to customize appearance
Testing and debugging - Tools and approaches
Version-specific guidance - Differences between Flet 0.x and 1.0+
Common mistakes to avoid
Resources and examples

This should serve as a helpful reference for AI assistants working with Flet projects!

Quick Start
Option 1: Quick Build
Reference the file with your instruction:

@AGENTS.md build a To-Do app in Python using Flet framework and then publish it as a desktop, mobile or web app
The AI builds your app immediately, asking only clarifying questions if needed.

Option 2: Guided Flow
Just reference the file:

@AGENTS.md
The AI asks you questions one at a time:

What would you like me to help you with? I can assist with:
- Building a Flet application (imperative or declarative style)
- Creating specific UI components or layouts
- Implementing navigation/routing
- State management
- Deployment to web, desktop, or mobile
- Debugging or troubleshooting existing code
- Converting between imperative and declarative styles
